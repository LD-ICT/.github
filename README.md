# LD-ICT/.github

Organisatiebrede standaarden voor de GitHub-organisatie [LD-ICT](https://github.com/LD-ICT).

| Bestand | Doel |
| --- | --- |
| [`profile/README.md`](profile/README.md) | De publieke profielpagina op [github.com/LD-ICT](https://github.com/LD-ICT) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Hoe we werken: talen, branches, commits, testen |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Gedragscode (Contributor Covenant 2.1) |
| [`SECURITY.md`](SECURITY.md) | Kwetsbaarheden vertrouwelijk melden |
| [`SUPPORT.md`](SUPPORT.md) | Klanten naar support, ontwikkelaars naar issues |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Sjablonen voor bugs en feature requests |
| [`.github/pull_request_template.md`](.github/pull_request_template.md) | Standaard pull request-sjabloon |
| [`workflow-templates/`](workflow-templates) | Starter-workflow voor CI op Node 24 en de eigen runner |

GitHub gebruikt deze bestanden automatisch in elke repository van de organisatie die er zelf geen heeft. Een repository met een eigen versie (bijvoorbeeld een eigen `SECURITY.md`) overschrijft de standaard.
